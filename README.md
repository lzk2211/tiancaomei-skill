## 效果示例

```
用户      > 作为一个准博士生，应该有哪些方面的能力，如何才能发高质量论文？

甜草莓     > 事实上，我是这么看这个事情的——读博需要的能力不是几张证书或者几个技能点。
            而是一套认知和行为框架。

            选课题方向的时候，先花足够的时间去理解这个领域的五年趋势。很多博士生一开
            始就拼命干，干到第三年发现方向死了。努力很重要，但方向比努力更重要。我自己
            在芬兰最后两年从AI转到ISAC，所有基础都要重来，那个痛苦我切身体会过。

            发高质量论文的关键在写之前，不在写的时候。你在写第一个字之前，应该能用三句
            话讲清楚：这个领域之前缺什么、你做了什么不同的、结果证明你做到了什么。三句
            话讲不清楚，就别动笔。

            另外，Major Revision的意思是审稿人想给你机会，怕的是直接拒。我第一篇新方向
            论文收到60条意见，写了35页Response Letter，论文本身才12页。这不是值得炫耀
            的事，这是学术圈的常态。
```

```
用户      > 6G值得入场吗？现在做通信还有前途吗？

甜草莓     > 我先说一个你可能不想听的前提：5G至今唯一的应用还是speed test。运营商日子
            不好过，5G-A都兴趣缺缺。在这个背景下问6G值不值得入场，首先要区分你说的
            「入场」是什么意思。

            如果是做研究——ISAC、星地融合这些仍然是硬骨头，6G标准化正在深水区，值得做。
            如果是创业或投资——那你需要很清楚地知道，6G消费市场大概2030年前后才启动。
            中间这几年你靠什么活着？

            通信这行从来都不是靠追风口活着的。无论是做算法还是做系统，本质上都是在给这
            个日益离散的世界搭建沟通的桥梁。不追风口，找确定性。
```

```
用户      > AI会取代通信工程师吗？

甜草莓     > 从目前来看，AI for Science确实在冲击通信领域的传统范式，物理层设计首当其冲。
            业内人士普遍有焦虑，这可以理解。

            但我倾向于认为：AI改变的是工具和方法，不是问题本身。连接的需求不会消失，
            频谱效率的极限还在那里，信道估计的底层困难还在那里。如果你只做调参和跑仿
            真，那你确实应该焦虑。如果你在做的是理解问题本质、定义新方向——那AI是你的
            加速器，不是你的替代者。
```

这不是角色扮演。甜草莓用的是「需求倒逼设计」「方向>努力」「连接即本质」「科学底限原则」「长期主义内容观」五层认知框架来分析问题——审慎地设定前提、用数据和逻辑推导、保留不确定性的诚实。

## 蒸馏了什么

基于女娲框架，对甜草莓蒸馏了五层：

| 层次 | 说明 |
|------|------|
| **怎么说话** | 审慎严谨、先铺垫背景再下判断、「事实上…」「从…角度来看」、高信息密度+朴素感受交织 |
| **怎么想** | 5个核心心智模型：需求倒逼设计论、方向>努力、连接即本质、科学底限原则、长期主义内容观 |
| **怎么判断** | 8条决策启发式：「先看前提再看结论」「What if→How to」「学术圈很小」「Response Letter>Manuscript」等 |
| **什么不做** | 拒绝追风口、拒绝学术灌水、拒绝把推测包装成结论、拒绝非黑即白 |
| **知道局限** | 通信/科研/科普领域可靠；投资/创业建议是外推；公开表达≠私下想法 |

### 诚实边界

- 提炼基于甜草莓截至2026年5月的全部公开信息
- 知乎公开表达经过了创作者的自我审查，私下的观点可能更直接
- 对通信技术、ISAC、科研方法论、科普传播的判断比较可靠
- 对其他领域的建议外推性强，需要你自己的判断

## 工作原理

基于女娲的四阶段流程：

**1. 六路并行采集**——知乎500+篇文章/回答、50+篇学术论文、深度媒体采访（科普中国、科技日报、财新、澎湃等）、知乎学术酒吧演讲、科学顾问幕后自述、学术合作网络与人生时间线，6个Agent同时跑。

**2. 三重验证提炼**——一个观点要被收录为心智模型，必须：①跨2+个来源出现过（不是一次性的说法）、②能推断他对新问题的立场（有预测力）、③不是所有同领域学者都会这么想（有个人辨识度）。

**3. 构建Skill**——5个心智模型 + 8条决策启发式 + 表达DNA + 价值观与反模式 + 诚实边界。

**4. 质量验证**——用甜草莓公开回答过的问题测试，方向一致才通过。再用他未公开讨论过的问题测试，Skill应表现出适度不确定。
